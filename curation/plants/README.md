# Plant Gene Set GO-Interpretation Gold Standard (`curation/plants/`)

This sub-corpus extends the hand-curated GO-interpretation gold standard to **vascular plants (`Viridiplantae`)**, spanning **30 curated gene sets** across the reference dicot model ***Arabidopsis thaliana*** and **five DOE Biological and Environmental Research (BER)** bioenergy and sustainable agriculture species:

- ***Arabidopsis thaliana*** (`NCBITaxon:3702`, `ARATH_*`, 14 sets) — primary plant genetic model (single-cell root and leaf atlases, secondary cell wall vs phloem vascular differentiation, abiotic stress regulons, cell-surface/SA/JA immune triad, and Strategy I iron vs PHR1 phosphate root nutrient foraging).
- ***Populus trichocarpa*** (`NCBITaxon:3694`, `POPTR_*`, 4 sets) — black cottonwood, the premier woody perennial bioenergy tree (normal secondary xylem monolignol/laccase lignification vs tension wood gelatinous-layer crystalline cellulose; autumn photoperiodic bud endodormancy & plasmodesmatal callose sphincters vs winter chilling-induced spring bud flush).
- ***Panicum virgatum*** (`NCBITaxon:38727`, `PAVIR_*`, 4 sets) — switchgrass, a flagship perennial C4 bioenergy grass (NAD-malic enzyme C4 Kranz anatomy: mesophyll initial $\text{HCO}_3^-$ fixation vs bundle sheath decarboxylation and Calvin-Benson-Bassham refixation; spring crown/axillary tiller bud outgrowth vs autumn shoot senescence and rhizome nitrogen remobilization).
- ***Sorghum bicolor*** (`NCBITaxon:4558`, `SORBI_*`, 3 sets) — bioenergy and drought-resilient C4 grass (*brown midrib* `bmr2`/`bmr6`/`bmr12` monolignol/secondary cell wall sink vs sweet sorghum soluble stem sucrose accumulation; post-flowering `Stg1`–`Stg4` stay-green drought tolerance).
- ***Thlaspi arvense*** (`NCBITaxon:13288`, `THLAR_*`, 3 sets) — field pennycress, a winter annual Brassicaceae oilseed cover crop engineered for sustainable aviation fuel and edible meal (seed very-long-chain erucic acid/TAG oil storage vs sinigrin glucosinolate defense; winter `FLC`/`VIN3`/`VRN` vernalization and floral transition).
- ***Brachypodium distachyon*** (`NCBITaxon:15368`, `BRADI_*`, 2 sets) — DOE grass and rhizosphere model (commelinid Type II cell wall feruloylated glucuronoarabinoxylan & mixed-linkage glucan biosynthesis; arbuscular mycorrhizal endosymbiosis & periarbuscular membrane phosphate/lipid exchange).

Like [`curation/cgsa/`](../cgsa/README.md), this sub-corpus uses the same LinkML schema ([`curation/schema/genesets_interpretation.yaml`](../schema/genesets_interpretation.yaml)) and 5-gate validator as the human gold standard while living in its own directory (`curation/plants/genesets/`) so human benchmark numbers in `curation/genesets/` remain untouched.

## Gene Identifier & Ontology Conventions

### 1. Native GAF `db_object_symbol` Gene Identifiers
Each gene set in [`curation/plants/genesets/lit_members.gmt`](genesets/lit_members.gmt) uses the native gene symbols from that species' official Gene Ontology Annotation (GAF) release so `genesets-rs` can run enrichment directly against each species' GAF without lossy cross-species orthology mapping:
- ***Arabidopsis thaliana*** (`tair.gaf.gz`): TAIR official gene symbols (`RHD6`, `GL2`, `CASP1`, `SLAC1`, `RBCS1A`, `SND1`, `SUC2`, `SEOR1`, `CBF3`, `PYR1`, `FLS2`, `ICS1`, `MYC2`, `FIT`, `F6'H1`, `PHR1`, `IPS1`, etc.).
- ***Populus trichocarpa*** (`goa_populus_trichocarpa.gaf.gz`): JGI/Phytozome locus symbols (`POPTR_0001s075400`, `POPTR_0006s126800`, etc.).
- ***Panicum virgatum*** (`goa_panicum_virgatum.gaf.gz`): Switchgrass v5/AP13 proteome symbols (`PVAP13_Pavir.9KG545200`, `PVAP13_Pavir.2NG449500`, etc.).
- ***Sorghum bicolor*** (`goa_sorghum_bicolor.gaf.gz`): Phytozome v3 locus symbols (`SORBI_3004G062500` [`Bmr2`], `SORBI_3004G071000` [`Bmr6`], `SORBI_3007G047300` [`Bmr12`], `SORBI_3001G469600` [`SbSUT1`], `SORBI_3004G074000` [`SbSWEET13A`], etc.).
- ***Thlaspi arvense*** (`goa_thlaspi_arvense.gaf.gz`): TaV2 genome locus symbols (`TAV2_LOCUS4912` [`FAE1`], `TAV2_LOCUS15555` [`CYP79B2`], `TAV2_LOCUS4073` [`FLC`], `TAV2_LOCUS11997` [`VIN3`], etc.).
- ***Brachypodium distachyon*** (`goa_brachypodium_distachyon.gaf.gz`): Bd21 reference locus symbols (`BRADI_2g36910v3` [`BdPMT1`], `BRADI_1g69327v3` [`BdPT4`], `BRADI_4g33550v3` [`BdSTR1`], etc.).

### 2. Plant Context Ontologies (`PO`, `TO`, `PECO`, `CHEBI`)
Plant anatomical structures, cell types, and agronomic traits are represented in `contexts` using OLS/OAK-validated terms from:
- **Plant Ontology (`PO`)**: e.g., `PO:0000262` (`trichoblast`), `PO:0000256` (`root hair cell`), `PO:0000263` (`non-hair root epidermal cell`), `PO:0000252` (`endodermis`), `PO:0000293` (`guard cell`), `PO:0004006` (`mesophyll cell`), `PO:0006023` (`bundle sheath`), `PO:0005848` (`secondary xylem`), `PO:0005417` (`phloem`), `PO:0000289` (`sieve element`), `PO:0000071` (`companion cell`), `PO:0000055` (`shoot system bud`), `PO:0004542` (`rhizome`), `PO:0009010` (`seed`).
- **Plant Trait Ontology (`TO`)**: e.g., `TO:0000303` (`low temperature stress response`), `TO:0000276` (`drought tolerance`), `TO:0000731` (`lignin content`), `TO:0000328` (`sucrose content`).
- **Plant Experimental Conditions Ontology (`PECO`)**: e.g., `PECO:0007163` (`cold temperature exposure`), `PECO:0007174` (`iron deficiency exposure`), `PECO:0007105` (`phosphate deficiency exposure`).
- **ChEBI (`CHEBI`)**: e.g., `CHEBI:6457` (`lignin`), `CHEBI:2365` (`(+)-abscisic acid`), `CHEBI:16914` (`salicylic acid`), `CHEBI:18292` (`jasmonic acid`), `CHEBI:24279` (`glucosinolate`), `CHEBI:27623` (`ferulic acid`), `CHEBI:17709` (`scopoletin`), `CHEBI:25520` (`nicotianamine`).

## Validation and Reporting

Run the 5-gate validator and precision/recall/F1 report over the plant corpus via `just`:

```bash
just curate-validate-plants
just curate-report-plants
```

See [`evals/plants/README.md`](../../evals/plants/README.md) for the comprehensive multi-species evaluation of GOA evidence variants (`all`, `no_contributes_to`, `iba_iea`, `iba`) and the taxonomy of nine plant-specific GO enrichment failure modes.
